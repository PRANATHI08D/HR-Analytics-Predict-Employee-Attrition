# 💼 HR Analytics - Predict Employee Attrition

## 📌 Objective
The aim of this project is to explore and analyze HR data to uncover the main causes of employee resignation (attrition) and to predict future attrition using machine learning.

---

## 🛠 Tools & Technologies
- **Python**: Data processing and modeling (Pandas, Seaborn, Scikit-learn, SHAP)
- **Power BI**: Interactive dashboard for data visualization
- **Jupyter Notebook**: For exploratory data analysis and model development

---

## 📁 Dataset
The dataset includes various employee attributes such as:
- `Age`, `Gender`, `Department`, `JobRole`
- `MonthlyIncome`, `YearsAtCompany`, `OverTime`, `JobSatisfaction`, etc.
- Target column: **Attrition (Yes/No)**
- -data set -`HR data.csv`
---

## 📊 Power BI Dashboard
The dashboard includes:
- **KPI Cards**: Total Employees, Average montly income, years at Company
- **Bar Chart**: Attrition by Department
- **Donut Chart**: Overtime and Attrition 
- **Stacked Column Chart**:  Monthly Income vs Attrition
- **column Chart**: Attrition ny Job Role

---

## 🧠 Machine Learning Model
A classification model was built to predict whether an employee will leave the company:
- **Model**: Logistic Regression / Decision Tree
- **Accuracy**: Included in `model_report.pdf`
- **Confusion Matrix**: Included in `model_report.pdf`
- **SHAP Value Analysis**: Performed to explain feature importance and predictions

---

## 📄 Deliverables
- 📊 `PowerBI_Dashboard.pbix` - Interactive dashboard file
- 🧠 `Attrition_Model.ipynb` - Model training notebook
- 📈 `model_report.pdf` - Accuracy and confusion matrix
- 💡 `Attrition_Suggestions.pdf` - Preventive insights based on data
- 📝 `README.md` - Project overview

---

## 🔍 Insights
- Departments with higher attrition include X and Y.
- Overtime and low work-life balance strongly correlate with attrition.
- Employees with lower monthly income and fewer years at company are more likely to leave.
